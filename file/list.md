# 기능 목록

지금까지 추가된 기능을 영역별로 정리한 목록. 각 항목은 간단한 설명만 담고, 자세한 배경은 CLAUDE.md를 참고.

## 온보딩

- **캐릭터 온보딩 대화**: 몇 번의 대화로 성격·말투·관심사를 파악해 캐릭터(페르소나)를 생성. 이름·이미지 포함.
- **ADHD 자가 문항**: 회원가입 직후, 캐릭터를 만들기 전에 ASRS(성인 ADHD 자가선별검사) 기반 6문항을 한 번씩 물어보고 포근한 말투로 결과를 알려줌. 언제든 건너뛸 수 있고, 진단이 아니라는 점을 명시.

## 일일 기록 (오늘 탭)

- **텍스트/음성 기록 입력**: 말하거나 타이핑하면 Gemini가 소비·일정·할일·사건으로 자동 구조화. 필수 정보(소비 금액)만 되묻고 나머지는 추정.
- **소비 카테고리 자동 분류**: 모델이 아니라 서버 키워드 매칭으로 분류(모델이 이 판단을 불안정하게 내려서 서버로 옮김).
- **생일·기념일 자동 인식**: "OO는 내 생일이야" 같은 말을 감지해 매년 반복되는 일정으로 자동 태깅.
- **완료 보고 자동 감지**: "~다 했어" 같은 말을 감지해 관련 일정·할일을 자동으로 완료 체크(문장 유사도로 가장 비슷한 항목 매칭).
- **자주 쓰는 문구**: 반복해서 쓰는 말을 저장해두고 탭 한 번으로 기록. 매번 다시 말하거나 타이핑하는 부담을 줄임.
- **밀린 일정 이관 제안**: 오늘 지난 미완료 일정·할일이 있으면 "오늘로 옮길까요?" 배너를 한 번만 부드럽게 제안(놓친 기간은 언급하지 않음).

## 일정 관리 (일정 탭)

- **캘린더 뷰 + D-day 배지**: 월별 캘린더로 일정·할일을 모아보고 임박한 항목에 D-day 표시.
- **할일 체크 표시**: 일정·할일을 완료 처리하면 목록에서 구분되어 표시.
- **생일·기념일 전용 표시**: 매년 돌아오는 날짜는 D-7 이내로 가까워졌을 때만 노출하고, 완료 체크박스는 제공하지 않음.

## 소비 관리 (소비 탭)

- **월별 소비 합계 + 카테고리 막대그래프**: 이번 달 총 소비와 카테고리별 비중을 한눈에 확인.
- **카테고리 커스터마이징**: 기본 7종 대신 사용자가 직접 카테고리를 추가·이름변경·삭제 가능.
- **개별 항목 재분류**: 자동 분류가 마음에 안 들면 항목별로 다른 카테고리로 바로 재지정.

## 다이어리 (다이어리 탭)

- **다이어리 자동 생성**: 오늘 남긴 기록과 캐릭터 말투를 바탕으로 Gemini가 다이어리를 작성.
- **필사 연출**: 타자기가 아닌 사각사각 연필 소리(Web Audio 합성)와 손글씨 애니메이션으로 재생.
- **피드백 반영 재작성**: 요청할 때만 캐릭터가 피드백을 반영해 다시 씀. 확인 안 해도 페널티 없음.
- **다이어리 형식 선택**: 문단형(기본) 또는 짧은 목록형 중 선택.
- **감정 요약(요즘 마음)**: 사건 기록에 담긴 감정 단어를 최근 7일/이번 달 기준으로 모아 막대그래프로 표시.

## 아카이브 & 리워드

- **캘린더 아카이브**: 지난 다이어리를 날짜별로 모아보기.
- **누적 마일스톤 → 쿠폰 지급**: 다이어리 10개마다(연속 기록이 아닌 누적 기준) 캐릭터 교체 쿠폰 지급. DB 트리거로 서버에서만 계산.
- **쿠폰으로 캐릭터 재구성**: 쿠폰을 쓰면 온보딩보다 더 여유 있는(8~12번 주고받음) 전용 대화로 이름·말투·이미지를 통째로 새로 만듦. 아무 때나 바꾸지 못하게 해서 로그 기록의 동기로 삼음.

## 설정 탭

- **저녁 리마인더 옵트인**: 기본 꺼짐, 켜도 죄책감 유발 문구 없음. 실제 이메일/푸시 발송은 포근함 컨셉과 안 맞다고 판단해 의도적으로 미구현(대상자 계산까지만).
- **다이어리 형식 토글**: 문단형/목록형 전환.
- **ADHD 자가 문항 결과 보기/다시 하기**: 온보딩 때 답한 결과를 다시 보거나, 원하면 다시 응답 가능.
- **내 데이터 내보내기**: 지금까지의 모든 기록(소비·일정·다이어리 등)을 JSON 파일 하나로 다운로드.

## 기술적 안정성

- **PWA 설치 지원**: 홈 화면에 앱처럼 설치 가능(manifest + 서비스워커).
- **PostgREST 1:1 임베드 버그 수정**: task_status/consumption_override처럼 raw_log_id가 자기 테이블의 기본키인 경우 배열이 아닌 객체로 내려오는 점을 바로잡음.
- **모델 반복-글자 방지**: 라이트 모델이 드물게 같은 글자를 반복하며 망가지는 문제를, 온보딩뿐 아니라 소비/일정/사건 추출 필드·다이어리 본문까지 공통 유틸로 방어.
